# Capivara Burgers

Website for Capivara Burgers: menu with prices, photos, and links to Instagram and Cash App.

- `index.html` is the whole site. Open it in a browser.
- `images/` holds the photos the page uses.
- `capivara-burgers-standalone.html` is the same page with the photos built in, for quick previews.

Links: https://www.instagram.com/capivara_burgers/ and https://cash.app/$capivaraburgersllc
